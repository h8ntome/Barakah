## Direction contract

THESIS: A calm, usable faith-aligned finance app, not five unreadable promotional phone panels. The single interactive device carries actual local demo workflows.

OWN-WORLD: Deep emerald #062D23 and #073B2C surround a #FCFBF7 canvas; mint #DFF3E3 surfaces, #10241D ink. DM Sans interface, Manrope amounts, Georgia-like brand/editorial type. Rounded 12–18px cards; consistent Lucide strokes.

STORY: Understand sample wealth, edit assets, see one coherent estimate, learn investing criteria, explore giving, and ask deterministic example questions. All claims remain visibly illustrative.

FIRST VIEWPORT: Desktop has a left-aligned brand, oversized editorial statement, compact five-destination navigation and restrained educational footer. One 410px-wide device sits at right, showing the emerald greeting, overlapping white financial overview, four actions, priorities and insight with persistent bottom tabs. Mobile removes the device frame and desktop panel. Signature interaction: saving assets updates both overview and zakat without resetting other tabs.

FORM: seed: none (pinned). User: “For desktop widths, show a branded emerald left-side panel, an oversized editorial product statement, a compact navigation list and a single realistic phone preview to the right.” “On a narrow mobile viewport, remove all ornamental desktop framing and present the app edge-to-edge.” Existing code and supplied concept corroborate this pin.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
