# Local fonts

DM Sans (Latin variable, weights 400–700) and Manrope (Latin variable, weights 400–800), downloaded from Google Fonts on 2026-11-14. Both use the SIL Open Font License; full licenses accompany these files.

Sources:
- https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/manrope

No font service is contacted at runtime. Georgia is a system-font fallback for the editorial/brand serif; no proprietary font is redistributed.
